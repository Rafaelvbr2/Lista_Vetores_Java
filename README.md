 Sobre a atividade

Esta atividade reúne oito exercícios de vetores desenvolvidos em Java, com o objetivo de praticar o conteúdo estudado em sala de aula.

Durante os exercícios, foram utilizados arrays, estruturas de repetição e condições para resolver situações como controle de estoque, vendas, reajuste de salários e organização de dados.

 Organização dos exercícios

1. Vendas da semana
2. Estoque crítico
3. Consulta de preço
4. Reajuste com teto
5. Pesquisa de satisfação
6. Fila do banco com prioridade
7. Ranking de vendedores
8. Juntando relatórios

 Como executar

Os exercícios estão separados em pacotes dentro da pasta `src`.

Para executar, basta abrir o projeto no IntelliJ IDEA, escolher o exercício desejado e executar a classe `Main.java`.

Observação Prof diego: Foram utilizados apenas arrays, sem ArrayList ou métodos prontos de ordenação.
