 Sobre a atividade



Durante os exercícios, foram utilizados arrays, estruturas de repetição e condições para resolver situações como controle de estoque, vendas, reajuste de salários e organização de dados.

 Organização dos exercícios

1. Vendas da semana
2. Estoque crítico
3. Consulta de preço
4. Reajuste com teto
5. Pesquisa de satisfação
6. Fila do banco com prioridade
7. Ranking de vendedores
8. Juntando relatórios

 

Observação Prof diego: Foram utilizados apenas arrays, sem ArrayList ou métodos prontos de ordenação.
