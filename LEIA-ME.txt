Lista de Vetores - Java

Abra a pasta Lista_Vetores_Resolvida no IntelliJ IDEA como projeto Java.
Os arquivos estao em src/exercicio1 ate src/exercicio8.
Cada exercicio tem seu proprio pacote e uma classe Main.
Clique com o botao direito no Main.java desejado e escolha Run Main.main().

Exercicio 3: os codigos e precos ja foram cadastrados no proprio codigo como exemplo.
Exercicio 5: se duas notas empatarem, a menor nota sera mostrada como mais votada.
Exercicio 8: digite as vendas de cada filial em ordem crescente.
